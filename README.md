# 📊 Daytrading Journal

Ein kostenloses, browserbasiertes **Trading Journal** für professionelle Daytrader. Perfekt zum Tracking von Trades auf **Futures, FX und Crypto**.

![License](https://img.shields.io/badge/License-MIT-green)
![Status](https://img.shields.io/badge/Status-Active-brightgreen)

## ✨ Features

✅ **Alle Asset-Klassen** - Futures (Indizes, Rohstoffe), FX, Bonds & Crypto  
✅ **Chart Screenshots** - Laden Sie Ihre Trades mit Screenshots hoch  
✅ **Echtzeit-Berechnung** - P&L, Entry/Exit, SL/TP Tracking  
✅ **Filterung** - Nach Instrument & Direction filtern  
✅ **Psychologie-Notizen** - Dokumentieren Sie Ihre Emotionen & Fehler  
✅ **Lokale Speicherung** - Alle Daten bleiben in Ihrem Browser (100% Datenschutz)  
✅ **Offline-nutzbar** - Funktioniert ohne Internet  
✅ **Responsive Design** - Perfekt auf Desktop, Tablet & Handy  

## 🚀 Schnelleinstieg

### Online (kostenlos)
Öffnen Sie direkt: **[trading-journal.html](https://victorschuller105.github.io/trading-journal/)**

### Lokal herunterladen
```bash
git clone https://github.com/victorschuller105/trading-journal.git
cd trading-journal
```
Dann einfach `index.html` im Browser öffnen.
